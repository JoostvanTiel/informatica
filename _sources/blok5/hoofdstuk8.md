# Hoofdstuk 8: Webshopproject - afronding en presentatie

## Weekdoel

Aan het eind van deze week kun je:

- je webshop testen en verbeteren;
- je project gestructureerd presenteren;
- reflecteren op je leerproces.

---

## 1. Eindcheck

Controleer:

- werkt alle CRUD?
- werkt validatie?
- zijn foutmeldingen duidelijk?
- is de code overzichtelijk?

---

## 2. Presentatie-inhoud

Laat zien:

1. je databaseontwerp;
2. een voorbeeld van SQL-queries;
3. hoe je PHP met de database koppelt;
4. welke keuzes je maakte voor veiligheid.

---

## 3. Reflectie

Beantwoord:

- wat ging goed?
- wat was lastig?
- wat heb je geleerd over SQL en PHP?

---

## 4. Inlevering

Lever in:

- broncode;
- korte documentatie;
- presentatiesamenvatting.
