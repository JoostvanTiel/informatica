LES 2.2: INNER JOIN (50 min)
───────────────────────────────────────────
Onderwerp: Gegevens combineren met INNER JOIN
Werkvormen: Uitleg + Oefening

Syntax (15 min):
```sql
SELECT u.voornaam, a.type
FROM gebruikers u
INNER JOIN abonnementen a ON u.id = a.gebruiker_id;
```

Oefeningen (25 min):
  1. SELECT voornaam + titel series (via genre_id)
  2. SELECT profiel + gebruiker voornaam (join profielen & gebruikers)
  3. SELECT aflevering titel + serie titel
  4. SELECT gebruiker + zijn abonnement type
  
Huiswerk-oefening (10 min): JOIN met 3 tabellen voorbereiding
