# Blok 5: SQL, PHP en webshop

In dit blok leer je hoe je met een relationele database werkt, hoe je data ophaalt en bewerkt met SQL, en hoe je die data gebruikt in een webapplicatie met PHP.

Je werkt met de nieuwe database **`nimmastream_2627_IMPROVED`**.

## Spoorboekje

|                   |                                                                                                         |
| ----------------- | ------------------------------------------------------------------------------------------------------- |
| **Onderwerpen:**  | SQL, relationele databases, PHP + MySQL, CRUD, basisbeveiliging, webshopproject                        |
| **Lesmateriaal:** | SQL-oefeningen, phpMyAdmin, SQL Island, boekhoofdstukken, praktijkopdrachten                           |
| **Toetsing:**     | Wekelijkse praktische opdrachten, mini-checks en eindproduct                                            |
| **Inhoud toets:** | SELECT, WHERE, ORDER BY, JOIN, UPDATE, DELETE, GROUP BY, subqueries, basis veilig programmeren in PHP |
| **Eindproduct:**  | Werkende mini-webshop met CRUD-functionaliteit                                                          |
